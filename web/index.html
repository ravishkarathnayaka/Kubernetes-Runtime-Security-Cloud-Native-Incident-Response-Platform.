Falco Behavioral eBPF Detection Rules

Production-grade rules deployed across the cluster via falco-custom-rules ConfigMap.

k8s_token_access.yaml CRITICAL

Detects unauthorized processes reading Kubernetes serviceaccount tokens.

- rule: Unauthorized Service Account Token Access
  desc: Detects token harvest attempts
  condition: >
    open_read and container and
    fd.name glob "/var/run/secrets/kubernetes.io/serviceaccount/token*" and
    not proc.name in (pause, kube-proxy, coredns)
  priority: CRITICAL
  tags: [credential_harvesting, T1552.007]
k8s_exec_terminal.yaml WARNING

Detects interactive shell (bash, sh, zsh) spawned inside pod container.

- rule: Interactive Shell Spawned Inside Pod
  desc: Detects interactive bash or shell session
  condition: >
    spawned_process and container and
    (proc.name in (bash, sh, zsh, ash) or proc.cmdline contains "sh") and
    not proc.pname in (containerd-shim, runc)
  priority: WARNING
  tags: [shell, mitre_execution, T1059]
k8s_container_escape.yaml CRITICAL

Detects breakout attempts via namespace changes, nsenter, or /proc tampering.

- rule: Container Escape Attempt
  desc: Detects breakout via sensitive host paths
  condition: >
    container and
    ((evt.type in (mount, setns, unshare)) or
     (open_write and fd.name startswith "/proc/sysrq-trigger") or
     (spawned_process and proc.name in (nsenter, chroot)))
  priority: CRITICAL
  tags: [escape, privilege_escalation, T1611]
quarantine-template.yaml CONTAINMENT

Dynamic zero-traffic NetworkPolicy synthesized by the Python controller.

apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: quarantine-compromised-workload
spec:
  podSelector:
    matchLabels:
      security.incident/target-pod: compromised-workload
  policyTypes: [Ingress, Egress]
  ingress: []
  egress: []
